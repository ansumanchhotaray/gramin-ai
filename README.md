# GraminAI • ग्रामीण साथी (Landscape / Desktop Edition)

A high-contrast, modern landscape dashboard recreation of **GraminAI / ग्रामीण साथी**, designed for visual clarity, offline accessibility, and rural utility.

## 🌟 Modules & Features
1. **Climate & Irrigation**
   - Interactive SVG dynamic fluid area chart with real-time Bezier calculation.
   - Dual sliders for "Adjust current field dryness" and "Expected overcast/rain forecast".
   - Dynamic Watering Plan status indicator (Sufficient, Schedule Irrigation, Urgent Irrigation Needed).
   - Precise dusk canal irrigation advisory alert banner.

2. **Grievance Letter Formatter**
   - Quick-select issue profile chips (Water Supply, Electricity Cut, Damaged Road, Crop Loss Survey).
   - Interactive signatory input binding with real-time text updates.
   - Formatted Official Prepared Form with dynamic date (9/12/2026).
   - Instant "Copy Application Text" button with clipboard feedback, plus print and WhatsApp sharing.

3. **First-Aid Guide**
   - High-contrast emergency situation selector (Snake Bite, Heat Stroke, Farm Cut / Injury).
   - Step-by-step numbered actionable checklist with bolded initial action words for high scannability.
   - Emergency banner with National Medical Helpline (102 / 108) and interactive "Call Now" emergency dispatch modal.

4. **Adla-Badli Share (Barter & Community Board)**
   - Mandi barter equivalence calculation engine with visual swap comparison and fair-value match indicators.
   - Peer-to-peer village asset sharing board for agricultural equipment (pumps, tractors, seeds, sprayers).
   - Minimal 2-field post submission form ("Item Name" and "Contact/Location").

5. **Bilingual Support & Accessible Design System**
   - One-click language switcher (`EN` / `हिंदी`) covering the entire interface.
   - Deep Forest Green theme (`#1B4325`), sage green backgrounds (`#EDF5F0`), crisp white cards, and high-contrast typography.

## 🚀 How to Run
Simply double click `index.html` in any browser, or run:
```bash
python -m http.server 8000
```
Then visit `http://localhost:8000`.
